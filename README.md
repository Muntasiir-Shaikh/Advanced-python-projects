# Advanced Python Projects 🐍

Welcome to my Advanced Python Projects repository!

This repository contains Python projects that I created to improve my programming skills and understand real-world applications of Python.

## Projects

### 1. Banking Management System
A simple banking application where users can:
- Select a bank account
- Deposit money
- Withdraw money
- Check account balance
- View account details

### 2. File Organizer
A simple file organization tool that automatically sorts files into different folders based on their extensions.

Features:
- Organize images
- Organize documents
- Organize videos
- Organize music files
- Organize other files

### 3. Book Management System
A basic library management application where users can:
- Add books
- View available books
- Search for books
- Issue books
- Return books

### 4. Password Management System
A demo password manager where users can:
- Add account details
- View saved accounts
- Search for accounts
- Delete accounts

Note: This is a learning demo and does not provide secure password storage.

### 5. Expense Tracker
A simple expense tracking application where users can:
- Add expenses
- View all expenses
- Calculate total expenses
- Search expenses by category
- Delete expenses

### 6. Contact Management System
A contact management application where users can:
- Add contacts
- View saved contacts
- Search for contacts
- Update contact details
- Delete contacts

### 7. Quiz Management System
A simple quiz application where users can:
- Answer quiz questions
- Choose from multiple options
- Check their answers
- Calculate their final score

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- VS Code
- Linux

## How to Run

Clone this repository:

```bash
git clone https://github.com/Muntasiir-Shaikh/advanced-python-projects.git
```

Open the project folder and run any Python file:

```bash
python Banking-Management-System/Bms.py
```

Other project commands:

```bash
python File-Organizer/Fo.py
python Book-Management/Bm.py
python Password-Management/Pm.py
python Expense-Tracker/main.py
```
